# Muazzam Portfolio

A personal portfolio website for Muazzam, a software engineer focused on secure web applications, full-stack development, cybersecurity, and cloud-backed systems.

The site presents a dark, editorial interface inspired by Fontshare-style catalog layouts, with oversized typography, thin grid borders, sharp spacing, and a minimal black-and-cyan visual identity.

Content is based on Muazzam's CV and resume, highlighting experience with React, PHP, MySQL, Docker, Cloudflare WAF, Flutter, Google ARCore, Google Cloud Platform, and database administration.

Featured work includes FF Portal, Survey Emailer, and AR Real Estate, alongside professional experience, education, technical skills, contact links, and selected career focus areas.

The project is built with Next.js, TypeScript, Tailwind CSS, GSAP, Lenis smooth scrolling, local Clash Display typography, and Vercel Speed Insights.
